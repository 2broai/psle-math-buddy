# Merli Math Buddy — Singapore MOE P1 to PSLE Interactive Math

An interactive, iPad-friendly web application designed for 6-year-old children entering Primary 1 (P1) in Singapore, building the foundation for the Primary 6 PSLE Mathematics examination.

## Features
- **5 Singapore Math Adventure Worlds**:
  1. **Merlion Bay**: Number Bonds, Ten-Friends & Make-10 Bridging Strategy
  2. **Marina Flyer**: Part-Whole & Comparison Bar Models
  3. **Gardens by the Bay**: 50+ Dynamic Visual Word Problems & Heuristics
  4. **Sentosa Island**: Number/Shape Patterns & Ordinal Numbers (Left/Right)
  5. **Jewel Changi**: Singapore Coins/Notes, Analog Clock Time & Picture Graphs
- **Infinite Question Generator**: Randomized numbers, names, Singapore contexts, and smart distractors so questions never run out.
- **Collectible Singapore Sticker Book**: 15 stickers to unlock across the 5 islands.
- **Parent's PSLE Strategy Corner**: 6-Year P1 → P6 Roadmap, AL1–AL8 scoring guide, and question-specific Parent Coaching Guides.
- **iPad PWA Ready**: Open in Safari on iPad and tap **Share → Add to Home Screen** for a full-screen app experience.
